# C++ 学习与课程练习

这是一个用于记录 **C++ 基础语法、面向对象编程、模板和数据结构练习** 的个人学习仓库。

仓库中的代码主要来自课程实验和日常练习，每个 `.cpp` 文件通常对应一个相对独立的知识点，可以单独阅读、修改和编译运行。

## 运行环境

推荐使用支持 C++11 及以上标准的编译器：

* GCC / MinGW-w64
* Clang
* Visual Studio
* Dev-C++ 或 Code::Blocks

查看本机是否已经安装 `g++`：

```bash
g++ --version
```

## 编译与运行

先克隆仓库：

```bash
git clone https://github.com/rongqingming050-source/-cpp-.git
cd -cpp-
```

建议新建一个目录存放编译结果：

```bash
mkdir build
```

以 `2025.3.22.cpp` 为例。

### Windows PowerShell

```powershell
g++ ".\cpp\2025.3.22.cpp" -std=c++11 -Wall -Wextra -o ".\build\string_demo.exe"
.\build\string_demo.exe
```

### Linux / macOS

```bash
g++ "./cpp/2025.3.22.cpp" -std=c++11 -Wall -Wextra -o "./build/string_demo"
./build/string_demo
```

仓库中的每个源文件大多拥有自己的 `main()` 函数，因此应当 **逐个编译**，不要一次性把所有 `.cpp` 文件放入同一条编译命令。

## 重点练习说明

### 自定义字符串类

`2025.3.22.cpp` 使用动态字符数组实现了一个简单的 `String` 类，涉及：

* 构造函数与析构函数
* 深拷贝
* 赋值运算符
* 字符串拼接
* 相等判断
* 删除指定字符

### 继承与多态

`2025.3.16.cpp` 和 `2025.3.28.cpp` 分别练习：

* 多继承与虚继承
* 抽象基类
* 纯虚函数
* 基类指针调用派生类函数

### 模板与集合运算

`2025.4.5.cpp` 使用类模板比较不同数据类型的大小。

`2025.4.6.cpp` 使用类模板完成两个集合的：

* 并集
* 交集
* 差集

### 单链表

`2025.4.9.cpp` 自定义了链表节点与链表类，实现了：

* 头部、尾部和指定位置插入
* 删除与查找
* 修改节点
* 合并链表
* 拆分链表
* 释放动态内存

## 当前仓库状态

这是一个课程学习记录仓库，而不是已经完成的工程项目，目前仍有以下情况：

1. 部分文件以日期或“未命名”命名，难以直接判断内容。
2. 仓库保存了较多 `.exe` 文件，会增加仓库体积。
3. 部分中文源码可能使用 GBK 编码，在 GitHub 或 UTF-8 终端中可能出现乱码。
4. 少数文件属于课堂草稿，存在代码不完整、标识符未加引号或说明文字混入源码等问题。
5. 当前没有统一的构建脚本，各练习需要分别编译。

因此，本仓库中的代码更适合用于回顾知识点、记录学习过程和继续修改，不建议直接用于正式项目。
